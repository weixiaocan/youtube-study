# YouTube 学习记录扩展

这是一个不接入 LLM 的 Chrome/Edge 工具。它在侧边栏显示当前视频字幕，并通过 `Alt + N` 保存时间戳和观看记录。

## 内容边界

工具只负责采集：

- 视频来源和频道信息；
- 完整字幕；
- 观看时主动保存的时间戳和记录。

它不会自动总结、复盘、回答问题或写文章。视频笔记作为 `video-note` 以原文形态进入 [[原始材料/index|原始材料]]，之后由整理流程按内容归类进 [[Wiki/index|Wiki]]，需要创作时再交给输出流程。

## 保存位置

一个视频只产生一篇可见笔记：

```text
原始材料/学习笔记/YouTube学习/YYYY-MM-DD 视频标题.md
```

保存时不做知识领域判断（`kb_status: raw`），归类进 Wiki 由后续整理完成。侧边栏需要的 JSON 缓存保存在 `.claudian/cache/youtube-study`，不参与知识库索引，可以重新生成。

## 安装或迁移

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启开发者模式，加载 `.claudian/tools/youtube-study/extension`。
3. 记下浏览器显示的扩展 ID。
4. PowerShell 运行：

```powershell
& ".claudian/tools/youtube-study/host/install.ps1" -ExtensionId "扩展ID"
```

默认假定本仓库位于 `<知识库>/.claudian/tools/youtube-study`。如果放在其他位置，加上 `-VaultPath "知识库根目录"` 显式指定；也可以加 `-PythonExe "python.exe 完整路径"` 指定 Python。

5. 刷新扩展和 YouTube 页面。

## 使用

1. 打开带字幕的 YouTube 视频和扩展侧边栏。
2. 点击“获取字幕”，工具只读取视频已有字幕并保存在隐藏缓存中，不会写入可见知识库。它优先选择英文，其次中文，再回退到其他已有语言，不执行语音转写。再次回到这个视频时，已获取过的字幕会从缓存自动恢复，不需要重复点击。
3. 播放时按 `Alt + N`，视频暂停并定位当前字幕。
4. 可以为这一条记录选择、拖入或粘贴多张截图；输入中的文字会保存在当前浏览器会话草稿中。
5. 输入记录后按 `Enter` 保存并继续；`Shift + Enter` 换行；`Esc` 取消。此时记录保存在 Chrome 本地，不需要立即入库。
6. 在“学习笔记”中点击时间按钮可跳回视频对应位置；点击“编辑”可修改文字、追加或移除截图。
7. 确认视频值得长期保留后，点击“保存到知识库”，才创建对应的单篇 Markdown 笔记，并把截图复制到 `原始材料/_附件/youtube-study`。

侧栏中的“清理过期缓存”只处理超过 30 天或超出最近 50 个上限、且从未入库的视频缓存；操作前会显示数量和预计空间。已入库视频、可见 Markdown 和仍被记录引用的截图不会被该按钮删除。

如果快捷键冲突，可在 `chrome://extensions/shortcuts` 中修改。

## 当前边界

- 只读取视频已有字幕，不执行语音转写。
- 没有字幕的视频不会创建完整字幕。
- 获取字幕、临时记录和保存到知识库彼此独立；仅点击“保存到知识库”才创建可见 Markdown。
- 浏览器本地存储保留一份观看记录状态；Markdown 是知识库中的唯一可见内容。
